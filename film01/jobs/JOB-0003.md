# JOB-0003
类型: image
分支: main
目的: 测试片 T01 的画风样帧，共 3 张，给用户挑画风。不花钱。
注意: 提示词用 v2（v1 作废：饭碗尺寸不对，构图和正式的 S02 不一致）。如果你已经用 v1 画过，保留那些图，再用 v2 各画一张。

## 参考图（每张都要用）
- `film01/refs/REF_fish_E_x3_v1.png`（角色：Q 版女仆大肥鱼）

## 要画的图（每张只画一次）
| 输出名 | 提示词文件 |
|---|---|
| STYLE_a | `film01/prompts/STYLE_a_v2.txt` |
| STYLE_b | `film01/prompts/STYLE_b_v2.txt` |
| STYLE_c | `film01/prompts/STYLE_c_v2.txt` |

每张的步骤：
1. `python film01/tools/collect_image.py --stamp`，记下打印出来的数字
2. 查看参考图，然后用你的生图工具，以提示词文件**原文**生成一张**横版**图片
3. `python film01/tools/collect_image.py --name <输出名> --since <数字> --prompt film01/prompts/<提示词文件名> --refs film01/refs/REF_fish_E_x3_v1.png --job JOB-0003`
4. `python film01/tools/fit_ratio.py images/<输出名>_v<N>.png`（N 是上一步打印出来的版本号），生成 16:9 版本

## 报告里额外写明
- 你的生图工具实际输出的尺寸；能不能直接指定 16:9 或其他尺寸（列出可选尺寸）
- 生成时有没有真正用上参考图（工具是否接受图片输入）
- 每张图和参考图对比，哪些角色特征没对上（呆毛、头饰、蓝色蝴蝶结的位置、鳍耳朵、渐变发色、围裙上的鲸鱼、尾巴），客观列出即可

## 完成标准
`images/` 下有 STYLE_a、STYLE_b、STYLE_c 各一张原图和一张 `_16x9` 版本，每张都带 json 说明；报告写好；推送到 main。
