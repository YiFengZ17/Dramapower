# JOB-0007
类型: video_submit + video_fetch
分支: main
目的: 提交 T01 的视频片段，下载后抽帧（**花钱**）。只提交用户已签批准单的镜头。

开工前：`git pull --ff-only origin main`，再运行 `python film01/tools/selfcheck.py`。ARK_API_KEY 或 ffmpeg 显示缺少，就不做任何提交，写报告说明。

## 范围
候选镜头：S01_v1、S02_v3、S04_v3、S06_v1、S05_v2。
只处理 `film01/approvals/` 下有同名批准单的镜头；没有批准单的跳过，在报告里写“等待用户批准”。**不要提交其他任何镜头参数文件。**
提交这一步需要联网，沙箱要求提升权限时，告诉用户“这一步会花钱提交 <clip>”。

## 1. 先单独试 S01_v1
```
python film01/tools/seedance.py submit shots/S01_v1.json
python film01/tools/seedance.py poll S01_v1 --wait 15
python film01/tools/inspect_video.py S01_v1
```
继续往下之前，必须同时满足：poll 显示 succeeded；`video_check/S01_v1/summary.json` 里时长在 3.8～4.3 秒之间、高度是 480。任何一条不满足，就停下，后面的镜头都不提交，把完整输出写进报告。

## 2. 其余镜头
S01_v1 通过检查后，按 S02_v3、S04_v3、S06_v1、S05_v2 的顺序对有批准单的镜头依次运行 `submit`。全部提交后，再逐个运行：
```
python film01/tools/seedance.py poll <clip> --wait 15
python film01/tools/inspect_video.py <clip>
```

任何一步失败都不重试，也不换参数。退出码 3（疑似欠费）表示立即全部停止。

## 3. 粗剪（不花钱）
上面全部成功后，运行：
```
python film01/tools/make_screen_insert.py
python film01/tools/assemble.py story/T01_edl_v1.json
```
第一条在 `video/S03_insert_v1.mp4` 已存在时会报错，忽略即可。第二条如果因为某个镜头缺失报错，把输出写进报告，不要改剪辑表。

## 报告里写明
- 每个镜头的 task_id、最终状态、`logs/api/<clip>.json` 里的 usage（token 数）、`video_check/<clip>/summary.md` 的内容
- 你**看过**的每段视频的客观情况，比如“第 2 秒脸变形”“出现两条尾巴”“背景闪烁”“书架上的东西在变”。导演看不到动态，只能靠你和用户
- 粗剪是否生成，`video_check/T01_cut_v1/timeline.md` 的内容

## 完成标准
推送：`logs/api/`、`video_check/`、报告。mp4 只留在本地，不提交。
