# JOB-0008
类型: video_submit + video_fetch + post
分支: main
目的: 一次性提交 T01 剩下的四个镜头，全部下载、抽帧后做粗剪（**花钱**）。JOB-0007 到此结束，不再执行。

用户已改规则：所有镜头一次生成，不再逐镜批准，也不再要求高度正好 480；只要每个镜头的尺寸统一即可。

开工前：`git pull --ff-only origin main`，然后 `python film01/tools/selfcheck.py`。ARK_API_KEY 或 ffmpeg 显示缺少，就不做任何提交，写报告说明。

## 1. 提交
候选镜头：S02_v3、S04_v3、S06_v1、S05_v3。只提交 `film01/approvals/` 下有同名批准单的镜头，没有的跳过并在报告里写明。**S01_v1 已经生成过，不要再提交。**
依次运行（需要联网，沙箱要求提升权限时，告诉用户“这一步会花钱提交 <clip>”）：
```
python film01/tools/seedance.py submit shots/S02_v3.json
python film01/tools/seedance.py submit shots/S04_v3.json
python film01/tools/seedance.py submit shots/S06_v1.json
python film01/tools/seedance.py submit shots/S05_v3.json
```
某个镜头提交失败的，不重试，继续提交下一个；但退出码 3（疑似欠费）表示立即全部停止。

## 2. 下载和抽帧
对每个已提交的镜头：
```
python film01/tools/seedance.py poll <clip> --wait 15
python film01/tools/inspect_video.py <clip>
```
抽帧以后，核对所有镜头的尺寸、帧率是否和 S01_v1 一致（864×496，24fps）。不一致的，在报告里写明，**不要停下**。

## 3. 粗剪（不花钱）
```
python film01/tools/make_screen_insert.py
python film01/tools/assemble.py story/T01_edl_v2.json
```
第一条在 `video/S03_insert_v1.mp4` 已存在时会报错，忽略即可。第二条如果因为缺少某个镜头报错，把输出写进报告，不要改剪辑表。

## 报告里写明
- 每个镜头的 task_id、最终状态、usage（token 数）、`video_check/<clip>/summary.md` 的内容
- 你**实际播放过**的每段视频的客观情况，例如“第 2 秒脸变形”“出现两条尾巴”“背景闪烁”“书架上的东西在变”。没播放过的，写“只看了抽帧”
- 粗剪有没有生成，`video_check/T01_rough_v1/timeline.md` 的内容

## 完成标准
推送：`logs/api/`、`video_check/`、报告。mp4 只留在本地，不提交。粗剪成片在 `film01/video/T01_rough_v1.mp4`，由用户播放。
