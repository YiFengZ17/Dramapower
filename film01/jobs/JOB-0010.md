# JOB-0010
类型: image + video_plan + video_submit + video_fetch
分支: main
目的: 重画 K0（不花钱）；生成报价（不花钱）；**只对用户已签批准单的镜头**提交视频（花钱）。

开工前：`git pull --ff-only origin main`，然后运行 `python film01/tools/selfcheck.py`。

## A. 重画 K0（不花钱，只画一次）
| 输出名 | 提示词文件 | 参考图 |
|---|---|---|
| K0_door_gap | `film01/prompts/K0_door_gap_v1.txt` | `film01/images/K1_typing_v2_16x9.png` |

1. `python film01/tools/collect_image.py --stamp`
2. 以提示词原文生成，参考图实际传入
3. `python film01/tools/collect_image.py --name K0_door_gap --since <数字> --prompt film01/prompts/K0_door_gap_v1.txt --refs film01/images/K1_typing_v2_16x9.png --job JOB-0010`
4. `python film01/tools/fit_ratio.py images/K0_door_gap_v1.png`

报告写明：和参考图比，房间里有没有东西挪了位置或多了少了（台灯、笔筒、书架上的东西、窗户、勺子、蝴蝶结），门缝有多宽。

## B. 报价（不花钱）
```
python film01/tools/seedance.py plan shots/S01_v4.json
python film01/tools/seedance.py plan shots/S02_v6.json
python film01/tools/seedance.py plan shots/S05_v5.json
python film01/tools/seedance.py plan shots/S06_v3.json
```

## C. 提交（花钱，只提交有批准单的）
候选镜头只有这三个：**S02_v6、S05_v5、S06_v3**。只提交 `film01/approvals/` 下有同名批准单的。**本工单不提交 S01_v4**，它要等导演看过新的 K0。旧版本镜头一律不提交。
需要联网，沙箱要求提升权限时，告诉用户“这一步会花钱提交 <clip>”。
```
python film01/tools/seedance.py submit shots/<clip>.json
```
全部提交完后，对每个镜头运行：
```
python film01/tools/seedance.py poll <clip> --wait 15
python film01/tools/inspect_video.py <clip>
```
任何一步失败都不重试，也不换参数。退出码 3（疑似欠费）表示立即全部停止。

## 报告里写明
- A 的观察，B 的四条完整输出
- C：每个镜头的 task_id、状态、usage、`video_check/<clip>/summary.md`
- 你**实际播放过**的每段视频的客观情况（变形、闪烁、多出来的肢体、物件变化、碗有没有飞出画面、米饭像不像白头发）。没播放过的，写“只看了抽帧”

## 完成标准
推送：`images/` 的 K0 两张图及 json、`requests/`、`logs/api/`、`video_check/`、报告。mp4 不提交。
