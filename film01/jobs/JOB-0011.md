# JOB-0011
类型: video_submit + video_fetch + post
分支: main
目的: 提交 S01_v5（**花钱**，只在有批准单时），然后拼出关键帧链版成片 T01_cut_v2（不花钱）。

开工前：`git pull --ff-only origin main`，然后 `python film01/tools/selfcheck.py`。

## 1. 提交 S01_v5（只在 `film01/approvals/S01_v5.json` 存在时）
没有批准单就跳过这一节，在报告里写“等待用户批准”，然后直接停止（第 2 节需要 S01_v5）。
```
python film01/tools/seedance.py submit shots/S01_v5.json
python film01/tools/seedance.py poll S01_v5 --wait 15
python film01/tools/inspect_video.py S01_v5
```
失败不重试，不换参数。退出码 3 表示立即停止。**其他任何镜头都不要提交。**

## 2. 拼成片（不花钱）
```
python film01/tools/assemble.py story/T01_edl_v6.json
```
需要的本地视频：S01_v5、S02_v6、S03_insert_v1、S04_v3、S05_v5、S06_v3（都在 `film01/video/`）。缺哪个就把报错原文写进报告，不要改剪辑表。

## 报告里写明
- S01_v5 的 task_id、状态、usage、`video_check/S01_v5/summary.md`
- 你**实际播放过**的情况：S01_v5 本身；成片里 S01→S02、S04→S05、S05→S06 这三处接缝有没有跳动或闪烁。没播放过的，写“只看了抽帧”
- `video_check/T01_cut_v2/timeline.md` 的内容

## 完成标准
推送 `logs/api/`、`video_check/`、报告。成片 `film01/video/T01_cut_v2.mp4` 只留在本地，由用户播放。
