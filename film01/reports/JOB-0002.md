## 1. 首尾帧 content

原文字段摘录：`first_frame`、`last_frame`。结构如下（示意地址，不是实际请求）：

```json
{"content":[
  {"type":"text","text":"提示词"},
  {"type":"image_url","image_url":{"url":"<首帧URL或data URL>"},"role":"first_frame"},
  {"type":"image_url","image_url":{"url":"<尾帧URL或data URL>"},"role":"last_frame"}
]}
```

两种目标模型均支持首尾帧。与全模态参考为互斥场景，不能混用 reference_image/video/audio 与严格首尾帧模式。[A](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

## 2. 参数位置、范围和模型差异

原文摘录：`request body`。顶层参数为推荐方式；resolution、ratio、duration、seed、camera_fixed、watermark 也可用提示词末尾参数的弱校验方式。generate_audio 用顶层布尔字段，文档未写它可用弱校验标记。[A](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

| 参数 | 可选值/目标模型限制 |
|---|---|
| ratio | 16:9、4:3、1:1、3:4、9:16、21:9、adaptive；2.5 首帧/首尾帧任务仅 adaptive |
| duration | 整数秒；2.5 为 4–30；mini 为 4–15；均另支持 -1 智能选择 |
| resolution | 2.5：480p/720p/1080p；mini：480p/720p |
| generate_audio | true/false，默认 true |
| watermark | true/false |
| seed | 通用字段范围 -1…2147483647；支持列表仅列 1.0 pro/pro fast，两个目标模型支持性文档未写 |
| camera_fixed | true/false；支持列表仅列 1.0 pro/pro fast，两个目标模型支持性文档未写 |

参数范围依据 [A](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)；输出规格另见 [C](https://ark.volcengine.com/region:cn-beijing/docs/video-generation-tutorial)。教程规格表原文摘录：`4~30 秒`、`4~15 秒`。不把通用参数展示等同于目标模型支持。

## 3. 图片传输和限制

原文格式摘录：`data:image/<图片格式>;base64,<Base64 编码>`。支持 PNG data URL；单图小于 30 MB，请求体不超过 64 MB；宽和高各 300–6000 px，宽高比 0.4–2.5。格式 jpeg/png/webp/bmp/tiff/gif，2.0 及以上额外支持 heic/heif。依据 [C 输入限制](https://ark.volcengine.com/region:cn-beijing/docs/video-generation-tutorial)。

首尾帧不要求同尺寸；比例不同会以首帧为主适配裁剪尾帧。原文摘录：`尾帧图片会自动裁剪适配`。[A](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

## 4. 查询状态、产物和有效期

原文字段摘录：`content.video_url`、`content.last_frame_url`、`return_last_frame`。
状态有 queued/running/cancelled/succeeded/failed/expired。创建时 return_last_frame=true 可取尾帧图。视频和尾帧链接有效期 24 小时；2.5 视频最多下载 100 次。普通任务 ID 保留 7 天；2026-10-28 10:00（UTC+8）后创建的 Draft ID 为 14 天，之前为 7 天。[B](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)

## 5. 欠费、余额不足、限流

原文摘录：`AccountOverdueError`、`OperationDenied.ServiceOverdue`、`TooManyRequests`。

| 情况 | HTTP / 错误码 |
|---|---|
| 欠费 | 403 / AccountOverdueError，或 OperationDenied.ServiceOverdue |
| 正余额但不足以执行本次视频任务 | 本次查阅文档未写专属映射，不将其等同于欠费 |
| RPM 限流 | 429 / ModelAccountRpmRateLimitExceeded、APIAccountRpmRateLimitExceeded，接入点另有 RateLimitExceeded.EndpointRPMExceeded |
| 并发限制 | 429 / ModelAccountConcurrentRequestsLimitExceeded |
| 队列任务数超限 | 429 / QuotaExceeded |

同一个 HTTP 状态可能对应不同原因，需结合 error.code/message；免费额度耗尽与调用频率超限不能只按 429 混为一类。[D](https://ark.volcengine.com/region:cn-beijing/docs/error-codes)

## 6. 计费和单价

原文摘录：`视频价格由 token 单价 和 token 用量 共同决定`。在线推理刊例价如下，单位元/百万 token：

| 模型/输出分辨率 | 输入不含视频 | 输入含视频 |
|---|---:|---:|
| 2.5 / 480p、720p | 70 | 42 |
| 2.5 / 1080p | 77 | 46 |
| 2.0 mini / 480p、720p | 23 | 14 |

页面按分辨率、是否输入视频区分；这两款有声/无声单价差异文档未写，不能套用其他模型的音频倍价。mini 的四折活动为 2026-08-07 至 10-07，当前已过期，不作为现价。图片输入不等同于视频输入；资源包价格不等同于按量单价。该价格页可获取的英文入口正文标记 2026-09-28，中文入口仅返回 2026-11-03 更新日期及空正文，因此上述为可核对的公开刊例值，实际结算以控制台账单为准。[E](https://docs.volcengine.com/docs/ark/model-pricing?lang=en&redirect=1)
